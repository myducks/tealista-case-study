# Project Scope

Tealista is a multilingual tea discovery and marketplace platform.

## Implemented

- Canonical tea and concrete-product catalog
- Seller offers, matching and comparable pricing
- Seller profiles and native shop products
- Product variants, stock and delivery configuration
- Cart, checkout and order workflows
- User lists, favourites, reviews and brewing-related features
- Editorial and administration workflows
- Web/PWA, browser extension, Telegram and Zepp OS clients
- Technical SEO and Google Merchant feed support
- Market/price-history observation and reconciliation tooling

## Feature-gated

Direct payment surfaces are currently disabled in production. The order/commerce domain exists, but payment activation is intentionally separate from implementation.

## Public repository boundary

This repository contains architecture and project documentation only. Application source, credentials, production configuration and sensitive business logic remain private.
