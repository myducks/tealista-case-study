# Project Scope

Tealista is a multilingual tea discovery and marketplace platform.

The project is focused on helping users explore tea, compare vendor offers and understand tea by origin, type, flavor and brewing profile.

## Product Scope

### Tea Discovery

- Tea catalog
- Tea type pages
- Origin pages
- Flavor pages
- Tea detail pages
- Filtering and browsing experience

### Marketplace Foundation

- Vendor offer presentation
- External shop redirect flow
- Vendor/shop profile foundation
- Offer visibility logic
- Click tracking foundation
- Future billing and vendor analytics preparation

### Content and Localization

- Multilingual content structure
- Language-specific routes
- Localized public pages
- SEO-oriented text fields
- Editorial tea descriptions and brewing guidance

### Administration Foundation

- Tea management workflows
- Vendor and offer data management foundations
- Content maintenance support
- Production-safe configuration separation

## Current Commercial Scope

The platform currently focuses on discovery, catalog visibility and external vendor offer flows.

Direct on-site payment functionality is not part of the public production flow until the commercial and payment process is fully ready.

## Public Repository Scope

This public repository is limited to project presentation:

- Project overview
- Technical stack
- Architecture summary
- Production engineering areas
- Screenshots and documentation

It does not include application source code or internal implementation details.
